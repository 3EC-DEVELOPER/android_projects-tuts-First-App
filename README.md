## About

The very first project from the course — a minimal "Hello World" Android application. Its purpose is to get the development environment set up, understand the structure of an Android project, and confirm that Android Studio, the SDK, and an emulator or device are all working correctly.

## Concepts Covered

- Setting up Android Studio and the Android SDK
- Understanding the structure of an Android project (manifests, res, java folders)
- `AppCompatActivity` and the `onCreate` lifecycle method
- Connecting an XML layout to an Activity via `setContentView`
- Running an app on an emulator or physical device

## Tech

- Language: Java
- Min SDK: Android 5.0+
